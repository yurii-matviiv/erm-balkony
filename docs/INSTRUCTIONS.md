# Інструкції до блоків сторінок

Кожен складний блок на сторінці (таблиця рекомендацій, розрахунок, автоматика) має кнопку **«Інструкція»** (іконка ❓) у шапці блока. Вона відкриває модальне вікно **на весь екран** з поясненням, як блок працює.

## Як додати до нового блока
1. У класі сторінки: `use App\Filament\Concerns\HasInstructionModal;`.
2. Метод `fooInstructionAction(): Action` → `return $this->instructionAction('fooInstruction', 'Назва — як це працює', 'filament.pages.foo-instruction', [змінні для в'ю]);`. Ім'я дії = ім'я методу без `Action`.
3. У blade блока: `<x-slot name="afterHeader">{{ $this->fooInstructionAction }}</x-slot>` всередині `<x-filament::section>`.
4. Текст — у `resources/views/filament/pages/foo-instruction.blade.php`. Числа (межі, дні, пороги) брати з констант класу, а не писати руками — інструкція не має розходитись з кодом.

Приклади: «Розподіл заявок між менеджерами» (`ManagerConversion`), вкладка «Заміри» (`Reminders`).

## Структура тексту інструкції
1. Що показує блок (2–3 речення; чи це рекомендація, чи факт).
2. Як читати: таблиця «колонка → що це».
3. Звідки дані і за який період.
4. Як рахується (кроки простою мовою).
5. Приклад на одному менеджері / записі.
6. Що з цим робити і на що зважати.

## Правила для самого блока
- Кожне число має підпис, що воно означає; голих відсотків без пояснення не лишаємо.
- Різницю часток пишемо в **п.п.** (відсоткових пунктах), не в «%».
- Рекомендація завжди позначена як рекомендація; при наведенні — підказка «що / чому».
- Проблемні стани (мало даних, обмеження) пояснюємо реченням у рядку, а не одним словом.
