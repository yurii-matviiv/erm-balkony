# Стандартний фільтр дат

## Стандартний фільтр дат (діє на ВСІХ таблицях з періодом)

Фільтр дат — НЕ всередині панелі фільтрів таблиці, а ЗАВЖДИ видимий бар над таблицею: перше поле — вибір періоду текстом (Сьогодні, Вчора, 7/30 днів, поточний/попередній місяць, рік, довільний), далі дві дати «З» і «По», які завжди показують конкретний діапазон (для «Сьогодні» обидві = сьогодні); жодних додаткових підписів із тими самими датами (було дублювання — прибрано). Ручна зміна дати перемикає період на «Довільний». Реалізація: трейт `App\Filament\Concerns\HasDateRangeBar` + `@include('filament.components.date-bar')` над таблицею + `applyDateRange($query, 'таблиця.колонка')` у запиті сторінки (для ListRecords — перевизначити `getTableQuery()`; приклад — `ListLeads` (по даті створення заявки) і `ListOrders` (по даті створення замовлення), за замовчуванням «Сьогодні» (сторінка може змінити через `defaultDatePreset()` — `ListOrders` стартує з «Поточний місяць»); обраний період запам'ятовується в сесії до кінця поточного дня, наступного дня знову «Сьогодні»). Пресети — `FinanceDateRange::presetOptions()`. На "Платежах"/"Аналітиці рахунків" той самий бар реалізований власним кодом (старіший варіант того ж патерну). Поля бару — пласкі, майже прямокутні (радіус 3px), без тіні, як поля в картці ліда. Нові сторінки з періодом робити лише так.

> Для вибору **одного значення** над таблицею (не періоду) є компонент `bar-select` у тому самому вигляді — див. [standards.md](standards.md) §4.3. Загальні правила стандартних елементів: [standards.md](standards.md).
